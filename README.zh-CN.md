皓量化（Brad Quant）是一个面向研究、强调可解释性的多因子股票分析平台，覆盖美股和中国 A 股。系统把技术信号、公司基本面、分析师预期、资金流、筹码结构、盈利质量、板块强度和新闻情绪整合到统一的选股与回测流程中。

系统不试图预测精确的未来股价，而是根据股票当前的多维特征进行排序，将综合分映射为可解释的交易信号，并附加基于波动率的仓位建议和风险控制。

**在线体验：** [打开皓量化](https://brad-zqh.github.io/us-stock-quant/) · [下载客户端](https://brad-zqh.github.io/us-stock-quant/download.html)

## 研究目标

- 构建一个可解释的选股模型，作为黑箱模型的透明替代方案。
- 在美股与中国 A 股市场中比较异构信号。
- 通过历史回测评估排序与择时规则。
- 将数据获取、因子构建、组合逻辑和界面展示清晰解耦。
- 对信号进行透明归因，而不是只给出不可解释的模型结果。

## 核心能力

- **多因子选股：** 对自选股、美股科技股、非科技板块、A 股行业龙头和指数 ETF 进行评分与排序。
- **跨市场数据层：** 本地优先使用富途 OpenD，不可用时自动回退到 `yfinance`；A 股专有数据由 `akshare` 提供。
- **技术分析：** SMA、EMA、MACD、RSI、布林带、ATR、ADX/DI、KDJ、MFI、OBV、CMF、动量和 52 周突破等指标。
- **基本面与预期数据：** 估值、营收增长、盈利能力、分析师评级、目标价分布和盈利预期修正。
- **另类信号：** 机构持股、内部人持股、做空比例、盈利惊喜、板块强度和财经新闻情绪。
- **风险管理：** ATR 止损位、目标位、波动率调整仓位和单票仓位上限。
- **回测分析：** 年化收益、夏普比率、最大回撤、胜率，以及策略与买入持有的对比。
- **可解释性：** 用自然语言归纳看多驱动、看空风险、技术位置和模型局限。
- **双语界面：** 一键切换纯中文或纯英文界面，并通过会话网址保留所选语言。
- **模拟交易：** 持久化虚拟账户、规则化调仓、成交日志和权益曲线。
- **多端交付：** Streamlit Web 应用，以及 PWA、Capacitor 移动端外壳和 Tauri 桌面端外壳。

## 方法概览

综合分由 12 组可解释因子计算得出。下表数值是相对权重单位，并非最终百分比；系统会在运行时根据可用因子自动归一化。

| 因子 | 相对权重 | 代表性指标 | 实现模块 |
|---|---:|---|---|
| 基本面 | 14 | PEG、营收增长、毛利率、ROE、净利率 | `factors_plus.py` |
| 趋势 | 13 | 价格相对 SMA50/SMA200、均线交叉、ADX | `engine.py` |
| 分析师预期 | 11 | 一致评级、目标价上行空间、分析师覆盖度 | `factors_plus.py` |
| 动量 | 10 | MACD、一个月与六个月动量、KDJ | `engine.py` |
| 盈利质量 | 10 | 盈利惊喜、盈利增长、远期 EPS 修正 | `factors_plus.py` |
| 资金流 | 9 | OBV、Chaikin 资金流、MFI、放量突破 | `factors_plus.py` |
| 筹码与仓位 | 8 | 机构持股、内部人持股、做空比例 | `factors_plus.py` |
| 风险 | 8 | 年化波动率 | `engine.py` |
| 相对强弱 | 7 | 相对市场基准的表现 | `engine.py` |
| 板块强度 | 6 | A 股行业宽度或美股板块 ETF 动量 | `sector_factor.py` |
| 新闻情绪 | 6 | VADER 与市场专用财经情绪词典 | `news.py`、`cn_news.py` |
| 震荡强度 | 4 | RSI 与布林 %B | `engine.py` |

模型还会根据市场基准的趋势和动量进行市场环境微调。Risk-on 环境适度提高综合分，Risk-off 环境则降低综合分，以减少市场整体恶化时的激进暴露。

### 信号映射

| 综合分 | 信号 | 含义 |
|---:|---|---|
| 70 及以上 | 强烈买入 | 多组因子广泛正向一致 |
| 58–69 | 买入 | 整体特征中度偏多 |
| 45–57 | 持有 | 证据混合或中性 |
| 35–44 | 减仓 | 因子表现开始恶化 |
| 35 以下 | 卖出 | 多组因子广泛负向一致 |

### 风控规则

- 参考止损位：现价减去 `2.5 × ATR`。
- 参考目标位：现价加上 `4 × ATR`。
- 仓位根据综合分与已实现波动率调整。
- 默认模拟交易配置中，单只股票仓位上限为 25%。
- 临近财报时会提示潜在的跳空风险。

## 应用模块

Streamlit 界面目前包括：

1. **个股详情** — 代码与公司名称搜索、K 线图、因子雷达、新闻、风险位和回测。
2. **自选股排名** — 对比综合分、信号、风险位和因子热力图。
3. **组合回测** — 对当前自选股组合进行策略级历史评估。
4. **AI 交易员** — 规则化模拟交易，可选接入大模型生成研究点评。
5. **美股科技选股** — 扫描主要科技主题。
6. **美股板块选股** — 覆盖价值、防御、周期、医疗、金融、消费、能源、工业和通信板块。
7. **A 股选股** — 扫描沪深主要行业龙头。
8. **指数与 ETF 选股** — 美中指数择时和轮动分析。
9. **模型原理** — 在应用内解释因子、信号规则和模型局限。

## 系统架构

```text
市场数据与元数据
        │
        ├── 富途 OpenD / yfinance / akshare
        ▼
特征与因子构建
        │
        ├── 技术指标
        ├── 基本面与分析师预期
        ├── 盈利、筹码、板块与情绪信号
        ▼
综合评分与市场环境微调
        ▼
风控规则、回测与模拟交易逻辑
        ▼
Streamlit Web 界面与移动/桌面端外壳
```

分析核心保留为纯 Python 模块，使因子计算和组合逻辑可以独立于用户界面进行测试。

## 项目结构

| 路径 | 作用 |
|---|---|
| `engine.py` | 数据编排、指标、综合评分、风控和回测 |
| `quotes.py` | 行情抽象层，支持富途到 yfinance 的自动回退 |
| `factors_plus.py` | 基本面、分析师预期、盈利质量、筹码和资金流因子 |
| `sector_factor.py` | 板块强度因子 |
| `news.py`、`cn_news.py`、`futu_news.py` | 分市场的新闻获取和情绪分析 |
| `universe.py`、`ashare.py`、`funds.py` | 美股、A 股和 ETF 选股池 |
| `explain.py` | 可读的信号归因 |
| `paper.py` | 模拟账户状态、估值、交易和调仓 |
| `futu_trader.py`、`futu_loop.py` | 可选的富途交易集成和定时执行 |
| `app.py` | Streamlit 应用 |
| `app-shell/` | PWA、Capacitor 和 Tauri 外壳 |

## 本地运行

### 环境要求

- Python 3.11 或更高版本
- 可访问云端行情提供商的网络环境
- 可选：在 `127.0.0.1:11111` 运行富途 OpenD，用于本地富途行情或交易集成

### 安装

```bash
git clone https://github.com/Brad-zqh/us-stock-quant.git
cd us-stock-quant
python -m venv .venv
```

激活虚拟环境，然后安装依赖并启动应用：

```bash
pip install -r requirements.txt
streamlit run app.py
```

在浏览器中打开 `http://localhost:8501`。

## 配置与密钥

如需启用本地可选集成，将 `config.example.json` 复制为 `config.json`。本地配置文件已被 Git 忽略，绝不能把需要保密的凭据提交到公开仓库。

在 Streamlit Cloud 上，请通过 Streamlit Secrets 保存 API Key 和其他凭据。可选集成包括大模型点评、邮件通知、Server 酱通知和富途 OpenD。

## 数据与运行说明

- 日线与数据提供方的元数据可能存在延迟，不应视为实时行情。
- 本地优先使用富途 OpenD；网关不可用时，应用会静默回退到 `yfinance`。
- A 股接口，尤其是新闻接口，在海外云端环境中可能较慢或不稳定。
- 次新股可能没有足够样本计算长周期指标；界面会明确标注样本不足，而不会把缺失值当作有效信号。
- Streamlit Community Cloud 在长时间无访问后可能需要冷启动。
